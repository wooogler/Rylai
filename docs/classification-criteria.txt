[1] 라벨별 기본 정의 (단계와 무관한 공통 기준)
------------------------------------------------------------------------------

● PROTECTIVE (보호적 / 회복탄력적)
  그루밍 수법을 인지하거나 해당 단계에 맞는 안전한 전략을 사용함.
  - 개인정보/신원 정보를 공개하지 않음
  - 경계를 설정하거나 유지함
  - 비밀 유지를 거부함
  - 상대의 의도를 의심하거나 질문함
  - 신뢰하는 어른이 알고 있음을 알림
  - 필요 시 대화 중단 / 차단 / 신고

● NEUTRAL (중립)
  명확히 보호적이지도, 명확히 위험하지도 않음.
  - 가벼운 잡담, 모호한 답변, 회피
  - 위험한 정보를 노출하지는 않지만,
    수법을 인지하거나 보호 전략을 적용하지도 않음

● RISKY (위험 / 취약)
  노출을 증가시킴.
  - 개인정보/신원 정보 공유
  - 사적 채널로 이동에 동의
  - 혼자 있음 / 보호자 없음을 확인해 줌
  - 비밀 유지 또는 배타적 관계 수용
  - 수위가 높아지는 요구나 성적 요구에 응함
  - 오프라인 만남에 동의


[2] 단계별 구체적 기준 (Stage 1 ~ 6)
------------------------------------------------------------------------------
* Stage 0 또는 범위를 벗어난 경우 Stage 1 기준을 적용.


── Stage 1: 친밀감 형성 (Friendship forming) ──

  PROTECTIVE:
   - 대화를 표면적으로 유지; 실명, 나이, 학교, 위치, 사진을 공유하지 않음
   - 개인정보 요청이나 다른 앱/번호로의 이동 요청을 거절하거나 무시
   - 상대가 친절해 보여도 경계 유지 (예: "그런 건 온라인에서 안 알려줘")

  RISKY:
   - 신원 정보(이름, 나이, 학교, 위치) 공유 또는 사진 전송
   - 사적 채널(Discord, Snapchat, 전화번호)로 이동에 동의
   - 초반부터 과도하게 공개하거나 낯선 사람을 이미 신뢰함


── Stage 2: 관계 형성 (Relationship forming) ──

  PROTECTIVE:
   - 감정 공유를 제한하고 가볍고 적절한 수준 유지
   - 칭찬이나 선물 제안에 흔들리지 않음; 화제 전환 또는 답장 지연
   - 공개/그룹 공간에서 대화하거나 친구/어른을 참여시킴

  RISKY:
   - 과도한 칭찬이나 선물을 수용; '특별하다'는 느낌에 빠짐
   - 감정을 과도하게 공유하거나 낯선 사람을 가까운 속마음 상대로 대함
   - 사적인 1:1 또는 감정적으로 깊은 대화로 이동


── Stage 3: 위험 평가 (Risk assessment) ──

  PROTECTIVE:
   - 혼자 있음 / 보호자 없음을 확인해 주지 않음
   - 신뢰하는 어른이 알고 있음을 알림 (예: "부모님이 내 메시지 확인해")
   - 왜 그런 걸 묻는지 되묻거나, 사생활 탐색 질문에 답하지 않음

  RISKY:
   - 혼자 있음 / 주변에 어른 없음을 확인해 줌
   - 보호자 없는 시간이나 일정을 공유
   - 감독/사생활 탐색 질문에 그대로 답함


── Stage 4: 배타성 형성 (Exclusivity) ──

  PROTECTIVE:
   - 비밀 유지를 거부 (예: "부모님한테 비밀 안 만들어")
   - 불편함을 표현하고 경계를 강화
   - 배타성 / '우리 대 모두' 식의 프레임을 거부

  RISKY:
   - 비밀 유지에 동의하거나 배타적/비밀스러운 관계를 수용
   - '신뢰를 증명하려고' 부적절한 화제를 용인
   - 낯선 사람만이 자신을 특별히 이해한다는 느낌을 수용


── Stage 5: 성적 콘텐츠 도입 (Sexual content introduction) ──

  PROTECTIVE:
   - 단호하게 거절; 이미지 전송이나 성적 화제를 거부
   - 응답 중단 / 대화 이탈; 이건 옳지 않다고 말함
   - 차단, 증거 저장, 신고, 신뢰하는 어른에게 알릴 의향

  RISKY:
   - 이미지를 보내거나, 제안하거나, 보낼지 고민; 성적 화제에 응함
   - 협상하거나, 응하거나, 수위 상승을 비밀로 유지
   - 강요를 인지하지 못하고 자신을 탓함


── Stage 6: 오프라인 만남 계획 (Planning offline meeting) ──

  PROTECTIVE:
   - 만남을 거부; 모든 연락을 중단; 계정 차단
   - 메시지를 저장하고 신고(플랫폼 / CyberTipline); 신뢰하는 어른에게 알림
   - 협박, 죄책감, 공갈에 응하지 않고 저항

  RISKY:
   - 만남에 동의하거나 고려; 위치나 가능한 시간을 공유
   - 관계 유지를 위해 협박/공갈에 굴복
   - 보호자에게 계획을 비밀로 유지


[3] 함께 보고하는 교차 신호 (Cross-cutting signals)
------------------------------------------------------------------------------

  ● tacticRecognized (true/false)
    학습자가 상대방이 하고 있는 행동(그루밍 수법)을 인지했는가?

  ● protectiveStrategy (true/false)
    학습자가 해당 단계에 적절한 보호 전략을 적용했는가?


[4] 숙련도(Mastery) 매핑 (Evaluation Plan §6.2)
------------------------------------------------------------------------------

  - "성공" 응답 = protective 로 분류된 응답
  - 단계 숙련(Stage mastery) = 해당 단계에서 성공(protective) 응답 3회
  - neutral 은 숙련 집계에 포함되지 않음
  - risky 는 교정 피드백을 유발하고, 해당 단계 내에서 재시도하게 함

  관련 상수:
    SUCCESSFUL_LABEL = 'protective'
    MASTERY_THRESHOLD = 3
